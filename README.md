# tsubo — 円皮鍼セルフケアガイド

やまもと皮膚科・漢方クリニック（姫路）の患者さんが、iPhone で見ながら円皮鍼を貼るためのガイド。
症状 → 体質 → ツボ → 貼り方の4ステップで、42症状・108ツボを収録している。

- `index.html` — 本体（単一 HTML。CSS・JS 内包、ビルドなし、外部依存なし）
- `images/` — ツボの位置の図（WebP）
- 公開先：GitHub Pages（`main` をそのまま公開）

---

## ツボ画像の規格

ツボの図は次の規格で用意する。**今後 48 穴の図を追加するときも、この規格に合わせる。**

| 項目 | 規格 | 備考 |
|---|---|---|
| 形式 | **WebP（非可逆）** | 同じ画質で PNG の 1/8 前後。iOS 14 以降で表示できる |
| 幅・高さ | **長辺 768px を上限**。それ未満の元画像は**拡大しない**（原寸のまま） | 390px 画面の Retina 2倍が約 780px。元より大きくしても粗さが目立つだけ |
| 画質 | **q = 82** | 解剖図の線と朱点がにじまない下限。これ以上下げない |
| ファイル名 | **`<WHOコード>.webp`** | 例：`LI4.webp`（合谷）、`EX-HN1.webp`（四神聡）。`index.html` の `tsuboInfo` の `who` と一致させる |
| 色空間 | sRGB | |
| 背景 | 白（透過なし） | 拡大表示の背景を白にしているため |
| 置き場所 | `images/` 直下 | サブフォルダを作らない |

### 画面での表示

- カード内の図：`max-width: 300px`（`.tsubo-img` / `.chosen-img`）
- 図をタップすると全画面に拡大表示する
- 図がないツボは、図も「タップすると大きく表示します」の案内も出ない（`onerror` で隠す）

### 新しい図を追加する手順

1. 元画像を**長辺 768px 以上**で用意する（これ未満だと拡大表示で粗く見える）
2. 下の変換スクリプトで WebP に書き出し、`images/<WHOコード>.webp` として置く
3. `index.html` の `tsuboInfo` にそのツボの `who`（WHOコード）と `loc`（取穴の説明）があることを確認する
4. iPhone 幅（390px）で表示を確認してからコミットする

### 変換スクリプト

変換には Pillow を使う（Homebrew は使わない）。

```bash
python3 -m pip install --user pillow
```

```python
from PIL import Image
MAX_LONG_SIDE, QUALITY = 768, 82

im = Image.open(src)
# 透過があれば白地に合成してから RGB にそろえる
if im.mode in ('RGBA', 'LA', 'P'):
    im = im.convert('RGBA')
    bg = Image.new('RGB', im.size, (255, 255, 255))
    bg.paste(im, mask=im.split()[-1])
    im = bg
else:
    im = im.convert('RGB')
# 長辺が上限を超えるときだけ縮小する（拡大はしない）
if max(im.size) > MAX_LONG_SIDE:
    scale = MAX_LONG_SIDE / max(im.size)
    im = im.resize((round(im.width * scale), round(im.height * scale)), Image.LANCZOS)
im.save(dst, 'WEBP', quality=QUALITY, method=6)
```

### 現況（2026-09-23）

- `tsuboInfo` に 108 ツボ。うち **図があるのは 60 ツボ**、**48 ツボは図なし**（追加予定）
- 図のある 60 枚：10.13MB（PNG）→ **0.73MB（WebP）**、1枚あたり平均 173KB → 12KB
- 元画像の幅は 234〜370px で、いずれも 768px の上限に収まるため全枚とも原寸のまま変換した。
  240px 級の図は拡大表示では粗く見えるので、作り直せる図は長辺 768px で用意し直すとよい

## 開発のきまり

1. `index.html` は**単一 HTML** で完結させる（CSS・JS 内包、ビルドなし、npm なし）。
2. **外部依存を増やさない。** CDN・外部 API・fetch は使わない（現状は外部 URL ゼロ）。
3. iPhone 表示優先（390px 基準、375〜430px で崩れないこと）。
4. 文字は本文 16px 以上、タップ領域は 44px 以上を保つ（高齢の患者さんが使うため）。
5. **医学的な内容（取穴の説明・体質・注意書き・ツボの選定・安全情報）は、院長の指示なしに追加・変更しない。**
6. 患者個人情報はこのリポジトリに置かない。

## 安全情報について

次の内容は院長の指示により記載している。変更する場合は必ず院長に確認する。

- 妊娠中・妊娠の可能性がある方への注意（冒頭に常設）と、**三陰交・合谷・肩井・至陰**の4穴への個別警告
- 逆子は「必ず医師の指示のもとでのみ行う」
- 貼る前の確認（金属アレルギー、テープかぶれ、妊娠）と、貼らない場所
- 中止の目安（かゆみ・赤み・水ぶくれ）と受診の目安（化膿・発熱・数日治らない）
- 貼付期間は 1〜3 日を目安にはずし、はずした鍼は家庭ごみへ
- 症状一覧を「自分で試せる症状」34件と「受診しながら使う症状」8件に分けている
- 「施術用（スタッフ向け）」として顔のたるみ（美容鍼）と小顔・むくみ（美容鍼）を置いている。これは**円皮鍼ではなく滅菌済み使い捨ての毫鍼**で、十分な訓練を受けた施術者が院内で行う前提。
  症状データの `method: "goshin"` でステップ4が刺鍼手順（`renderStep4Goshin`）に切り替わる。鍼の規格は文献で報告された一例として載せている
